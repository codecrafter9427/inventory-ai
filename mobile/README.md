# Inventory AI — Android shell

Kotlin + Jetpack Compose native Android project (not WebView).

## Open in Android Studio

1. Open `products/inventory-ai/mobile` as a Gradle project.
2. Let Android Studio download the Gradle wrapper / SDK if prompted.
3. Run the `app` configuration on an emulator or device.

## Scaffold scope

- Demo login screen
- Home shortcuts that navigate to Coming Soon stubs
- No barcode, receiving, counts, transfers, or offline queue yet

## Note on Gradle wrapper JAR

`gradle/wrapper/gradle-wrapper.properties` is present. If `gradlew` / `gradle-wrapper.jar` are missing, use Android Studio’s “Create Gradle Wrapper” or run `gradle wrapper` from a machine with Gradle installed.
